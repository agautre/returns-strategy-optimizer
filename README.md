# returns-strategy-optimizer
Sotira is a lightweight returns strategy simulator. It lets teams adjust monthly
orders, return rate, average order value, and handling cost, then compare how
restocking, discounting, or recycling affects recovered value, operations cost,
inventory recovery, and future sales.

## Run locally

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

The project has no build step or dependencies, so it can be deployed directly
to Vercel as a static site.
